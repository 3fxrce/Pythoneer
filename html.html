Lesson 1: What is HTML?

HTML stands for HyperText Markup Language.

It is used to create the structure of websites.

Lesson 2: HTML Headings

Headings are used for titles.

<h1>Hello World!</h1>

This creates a large heading.

Lesson 3: HTML Paragraphs

Use the paragraph tag to write text.

<p>I am learning HTML!</p>

Lesson 4: HTML Images

The img tag displays an image.

<img src="image.jpg" alt="My image">

Lesson 5: HTML Links

Links allow people to visit other pages.

<a href="https://google.com">Visit Google</a>

Lesson 6: HTML Buttons

Buttons allow users to interact with websites.

<button>Click Me!</button>
